## 设计语言

- 深色 Treasury Command Center；
- 主色 lime，辅助 cyan、blue、violet、coral；
- 结构感来自审计轨迹、策略边界、节点和资金流；
- 不使用夸张加密货币符号、金币雨或无法验证的链上数字；
- 所有真实 tx、钱包和 provider 状态必须来自公开证据。
